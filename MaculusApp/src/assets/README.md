# Whisper diagnostic sample

`whisper-self-test.wav` is the JFK inaugural-address speech sample also used by
[whisper.cpp](https://github.com/ggml-org/whisper.cpp/blob/master/samples/jfk.wav)
and the [reference demo](https://github.com/betomoedano/whisper-speech-recognition).
The recording is US federal-government/public-domain speech, not user audio.
Only the first eight seconds are decoded for the optional offline model test.
It is never played, used as a command, or uploaded. The test is available only
while a Maculus session is stopped.
