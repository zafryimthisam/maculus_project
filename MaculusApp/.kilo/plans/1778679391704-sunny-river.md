# React Native 0.75+ Migration Fix Plan

## Analysis of Incompatibilities

### Current State
- React Native version: 0.75.4 ✅
- Project structure: Mixed Java/Kotlin implementation
- Autolinking: Working ✅
- Custom native modules: ImageProcessorPackage (Java)
- Native modules compatibility:
  - @react-native-community/slider: Compatible (but v4.5.5 has Android new arch issues)
  - react-native-background-timer: Needs fork (@boterop/react-native-background-timer v2.6.0)
  - react-native-fast-tflite: Has new arch compatibility issues (disable new arch or use fork)
  - react-native-network-info: Compatible
  - react-native-tts: Compatible

### Identified Issues
1. **Gradle Configuration Issues**
   - Missing Android Gradle Plugin version in root build.gradle
   - Old NDK version (25.1.8937393 → 26.1.10909125)
   - Missing kotlinVersion in app build.gradle dependencies
   - jscFlavor not defined for JSC fallback
   - gradle.properties missing kotlinVersion property and Java 17 configuration

2. **Deprecated APIs**
   - ImageProcessorModule extends `ReactNativeContextBaseJavaModule` (deprecated → `ReactContextBaseJavaModule`)

3. **File Conflicts**
   - Duplicate MainApplication.java and MainApplication.kt
   - Duplicate MainActivity.java and MainActivity.kt
   - Manual package addition in Java version, commented in Kotlin

4. **Native Module Updates**
   - react-native-background-timer needs update to compatible fork
   - react-native-fast-tflite may need new arch disabled or fork

### android/app/src/main/java/com/maculusapp/ImageProcessorModule.java
```java
package com.maculusapp;

import android.graphics.Bitmap;
import android.graphics.BitmapFactory;
import android.graphics.Matrix;
import android.util.Base64;
import com.facebook.react.bridge.*;
import java.io.ByteArrayOutputStream;
import java.nio.ByteBuffer;
import java.nio.ByteOrder;

public class ImageProcessorModule extends ReactContextBaseJavaModule {
    private static final int YOLO_SIZE = 640;
    private static final int SCENE_SIZE = 224;

    public ImageProcessorModule(ReactApplicationContext reactContext) {
        super(reactContext);
    }

    @Override
    public String getName() {
        return "ImageProcessor";
    }

    @ReactMethod
    public void preprocessYOLO(String base64Image, Promise promise) {
        try {
            WritableMap result = preprocess(base64Image, YOLO_SIZE, true);
            promise.resolve(result);
        } catch (Exception e) {
            promise.reject("PREPROCESS_ERROR", e.getMessage());
        }
    }

    @ReactMethod
    public void preprocessScene(String base64Image, Promise promise) {
        try {
            WritableMap result = preprocess(base64Image, SCENE_SIZE, false);
            promise.resolve(result);
        } catch (Exception e) {
            promise.reject("PREPROCESS_ERROR", e.getMessage());
        }
    }

    private WritableMap preprocess(String base64Image, int targetSize, boolean normalizeTo01) {
        byte[] decoded = Base64.decode(base64Image, Base64.DEFAULT);
        Bitmap original = BitmapFactory.decodeByteArray(decoded, 0, decoded.length);

        Bitmap scaled = Bitmap.createScaledBitmap(original, targetSize, targetSize, true);
        int[] pixels = new int[targetSize * targetSize];
        scaled.getPixels(pixels, 0, targetSize, 0, 0, targetSize, targetSize);

        ByteBuffer buffer = ByteBuffer.allocateDirect(targetSize * targetSize * 3 * 4);
        buffer.order(ByteOrder.nativeOrder());

        for (int i = 0; i < pixels.length; i++) {
            int pixel = pixels[i];
            float r = ((pixel >> 16) & 0xFF);
            float g = ((pixel >> 8) & 0xFF);
            float b = (pixel & 0xFF);

            if (normalizeTo01) {
                r /= 255.0f;
                g /= 255.0f;
                b /= 255.0f;
            }

            buffer.putFloat(r);
            buffer.putFloat(g);
            buffer.putFloat(b);
        }

        byte[] outBytes = new byte[buffer.capacity()];
        buffer.rewind();
        buffer.get(outBytes);

        String outBase64 = Base64.encodeToString(outBytes, Base64.NO_WRAP);

        WritableMap map = Arguments.createMap();
        map.putString("base64", outBase64);
        map.putInt("width", targetSize);
        map.putInt("height", targetSize);
        return map;
    }
}
```
